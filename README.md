# 3113 Adventures – Version 3.0

## Neu
- OpenStreetMap-POI-Suche über Overpass API
- Suche nach Camping/Hütten, Trinkwasser, Einkauf, ÖV, Toiletten und Apotheken
- wählbarer Suchradius und Overpass-Server
- optionale Filterung nach Entfernung zum importierten GPX-Track
- Treffer vor dem Speichern auswählen
- Quellenangabe, OSM-ID und Prüfdatum pro importiertem Ort
- Duplikaterkennung bei wiederholten Suchen
- nächste gespeicherte Orte auf dem Dashboard
- alle Funktionen aus Version 2.2 bleiben erhalten

## Datenqualität
OpenStreetMap-Daten können unvollständig oder veraltet sein. Importierte Treffer sind deshalb nicht automatisch als selbst geprüft markiert. Öffnungszeiten, Zugänglichkeit und tatsächliche Verfügbarkeit müssen unterwegs geprüft werden.

## Kontrolle
Oben rechts muss `v3.0` stehen.
