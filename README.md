# 3113 Adventures – Sprint 9.5.1 Hotfix

## Etappen
- Speichern und anschliessendes Rendern sind jetzt getrennt.
- Ein Anzeigeproblem wird nicht mehr fälschlich als Speicherfehler gemeldet.
- Etappenkoordinaten werden defensiv dargestellt, falls bei einem Sonderfall Koordinaten fehlen.
- Nach dem Speichern bleibt eine klare Statusmeldung erhalten.

## Schuhe
- Ein Schuhartikel kann pro Tour nur einer Person zugeordnet werden.
- Bei Person 1 gewählte Schuhe sind bei Person 2 deaktiviert und umgekehrt.
- Die Regel wird zusätzlich beim Speichern geprüft und kann nicht über die Oberfläche umgangen werden.

## Kontrolle
Oben rechts muss `v4.0.0 · Sprint 9.5.1` stehen.
