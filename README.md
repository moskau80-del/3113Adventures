# 3113 Adventures – Version 2.0.2

## Behoben
- eigenes Register `NST-Abschnitte` wieder ergänzt
- alle offiziellen NST-Abschnitte werden aus der Datendatei angezeigt
- Heidschnuckenweg ist speziell markiert
- Suche und Filter für Abschnitte
- Leaflet wird neu über jsDelivr geladen
- verständliche Fehlermeldung, falls die Kartenbibliothek nicht erreichbar ist
- Kartencontainer wird beim Öffnen zuverlässig neu berechnet
- GPX-Track, Etappen und Orte aus Version 2.0.1 werden übernommen

## Wichtig zu Orten
Es werden weiterhin keine ungeprüften Camping-, Wasser- oder Einkaufspunkte vorinstalliert.
Eigene Orte kannst du unter `Orte` oder durch Tippen auf die Karte anlegen.

## Kontrolle
Oben rechts muss `v2.0.2` stehen. In der Navigation muss `NST-Abschnitte` sichtbar sein.
