# 3113 Adventures – Version 4.0.0 / Sprint 9.0

## Bestandskontrolle für Packlisten
- Packlistenmenge kann den vorhandenen Artikelbestand nicht mehr überschreiten.
- Bestand wird über Person 1 und Person 2 gemeinsam geprüft.
- Beispiel: Bestand 1 -> insgesamt maximal 1 Stück über beide Packlisten.
- Beispiel: Bestand 5 -> Person 1 = 3 und Person 2 = 2 möglich; mehr nicht.
- Mengenfeld erhält automatisch den maximal möglichen Wert.
- Direktes Hinzufügen und Drag & Drop prüfen den Bestand ebenfalls.
- Bei Überschreitung erscheint eine verständliche Meldung.
- Entfernen eines Artikels gibt den Bestand für die andere Person sofort wieder frei.

## Kontrolle
Oben rechts muss `v4.0.0 · Sprint 9.0` stehen.
