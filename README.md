# 3113 Adventures – Version 4.0.0 / Sprint 9.11

## Mein Transa & Packlisten
- Bestand zeigt jetzt direkt `frei von Gesamtbestand`
- bereits eingepackte Menge wird pro Artikel angezeigt
- Zuweisungsbuttons werden deaktiviert, wenn kein Bestand mehr frei ist
- Bestandsanzeige aktualisiert sich direkt nach einer Zuweisung
- Personennamen bleiben auf den Zuweisungsbuttons erhalten
- Packgewichte in der Seitenleiste werden nach Änderungen aktualisiert
- bestehende Mengenbegrenzung über beide Personen bleibt aktiv

## Ziel
Mein Transa und die Packlisten sind damit funktional für den Abschluss vorbereitet.
