# 3113 Adventures – Version 4.0.0 / Sprint 9.1

## Packlisten-Zuweisung vereinfacht
- Drag & Drop entfernt
- direkte Zuweisung über `→ Person 1` und `→ Person 2`
- beim Zuweisen wird gefragt, wie viele Stück übernommen werden sollen
- Anzeige des noch verfügbaren Bestands
- maximale Zuweisung bleibt auf den realen Bestand über beide Personen begrenzt
- wenn ein Artikel bereits in der Packliste ist, wird die neue Menge addiert
- bestehende Mengen können weiterhin direkt in der Packliste verändert werden
