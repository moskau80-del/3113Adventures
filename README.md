# 3113 Adventures – Version 4.0.0 / Sprint 8.4

## Neu
- Artikel aus `Mein Transa` per Drag & Drop direkt auf Person 1 oder Person 2 ziehen
- Drop-Zonen zeigen die frei gewählten Personennamen
- bereits vorhandene Artikel werden nicht doppelt in dieselbe Packliste gelegt
- nach Drop wird direkt auf die Packliste der betreffenden Person gewechselt

## Darstellung optimiert
- Artikelliste jetzt als responsives Kartenraster
- mehrere Artikel nebeneinander auf grossen Bildschirmen
- auf kleinen Bildschirmen automatisch einspaltig
- Inhalte, Metadaten und Aktionen sauberer gruppiert
- Karten haben gleiche Grundstruktur und bessere Ausrichtung

## Kontrolle
Oben rechts muss `v4.0.0 · Sprint 8.4` stehen.
