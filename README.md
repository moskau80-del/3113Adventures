# 3113 Adventures – Version 4.0.0 / Sprint 7.6

## Änderungen
- Sprint-Bezeichnungskarte aus der Übersicht vollständig entfernt.
- Versionsanzeige oben bleibt zur technischen Kontrolle erhalten.
- Track-Editor erweitert:
  - Klick auf die Karte fügt einen zusätzlichen Bearbeitungspunkt ein.
  - Zwischenpunkte können per Rechtsklick entfernt werden.
  - Punkte bleiben per Drag & Drop verschiebbar.
  - Rückgängig, Zurücksetzen, Speichern und Abbrechen bleiben erhalten.
- Änderungen werden weiterhin niemals automatisch gespeichert.
- alle Hotfixes aus Sprint 7.5.3 bleiben enthalten.

## Hinweis
Automatisches Wanderrouting entlang realer Wege ist noch nicht enthalten. Sprint 7.6 verbessert zunächst die manuelle Trackbearbeitung.

## Kontrolle
Oben rechts muss `v4.0.0 · Sprint 7.6` stehen. In der Übersicht gibt es keine Sprint-Karte mehr.
